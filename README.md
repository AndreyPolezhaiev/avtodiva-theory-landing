# Avtodiva Landing (Theory Course, Category B)


## 💡Overview

Sales landing page for the AvtoDiva video course on traffic rules theory (category B). A static, mobile-first single page with no build step.


## 🛠 Tech Stack

* **Frontend:** HTML, CSS (BEM, custom properties).


## 📂 Project Structure

* `src/index.html`: Page markup.
* `src/styles.css`: Global styles and the entry point that imports all styles.
* `src/styles/utils/variables.css`: Design tokens (colors, fonts, sizes).
* `src/styles/blocks/...`: One file per BEM block (`hero`, `btn`, `lesson`, `faq`, ...).
* `src/assets/images/...`: Images grouped by page section.


## 🚀 How to Run
1. Clone the repository: `git clone https://github.com/AndreyPolezhaiev/avtodiva-landing.git`
2. Open `src/` with any static server (e.g. VS Code Live Server).
